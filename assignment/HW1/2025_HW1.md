### 2.1

```
thetalist, success = InverseKinematics_in_space(Blist, M, T, thetalist0, eomg, ev)
```

Computes inverse kinematics in the space frame for an open chain robot.

* **input1**: `Blist`: The joint screw axes in the end-effector frame when the manipulator is at the home position.
* **input2**: `M`: The home configuration of the end-effector.
* **input3**: `T`: The desired end-effector configuration Tsd.
* **input4**: `thetalist0`: An initial guess θ₀ ∈ Rn that is "close" to satisfying T(θ₀) = Tsd.
* **input5**: `eomg`: A small positive tolerance on the end-effector orientation error. The returned joint variables must give an end-effector orientation error less than ϵω.
* **input6**: `ev`: A small positive tolerance on the end-effector linear position error. The returned joint variables must give an end-effector position error less than ϵv.
* **return1**: `thetalist`: Joint variables that achieve T within the specified tolerances.
* **return2**: A logical value (bool) where TRUE means that the function found a solution and FALSE means that it ran through the set number of maximum iterations without finding a solution within the tolerances ϵω and ϵv.
